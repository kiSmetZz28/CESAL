# Static Assets

## demo.mp4

The demo video (`demo.mp4`) is **not tracked in this repository** — it exceeds
GitHub's 100 MB file size limit.

The dashboard's **"Watch Demo"** button plays `/static/demo.mp4`, so the button
only works when a copy of the file is placed here. The video is a convenience
for demonstrations; it is not needed to run or evaluate CESAL.
