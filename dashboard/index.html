Note on the online demo. For ease of online demonstration, the online demo (https://kismetzz-ceco-lad.hf.space/) runs both the edge-side LAD and the cloud-side LAD, together with the inference routing policy, within the same execution environment. This design is intended only to provide reviewers and readers with a convenient way to verify the complete CESAL workflow online. In the actual deployment setting and in our experiments, however, the edge-side phase is deployed independently on resource-constrained edge devices, such as Raspberry Pi devices.

Preprocessor output — sliding context window matrix (— events · each row = one event · columns = context steps back · · = NO_EVENT padding)
The preprocessor applies a sliding context window of length 10 over each session. For each event, the model sees the 10 preceding event IDs as context (filled with NO_EVENT=−1337 when no preceding event exists). These rows are fed row-by-row into the AI model (windows of 100 events at a time).
